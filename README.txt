# Lakshya Co-Living website

Open `index.html` in a browser.

## Add the real property photos
The site is already structured for the business photos, but the Google Maps short link did not expose downloadable original photo files in the browsing environment. I intentionally used clearly labeled placeholders rather than presenting unrelated stock images as the property.

Replace these files in `images/`:
- hero-placeholder.svg -> hero.jpg
- room-placeholder.svg -> room.jpg
- gallery-1-placeholder.svg -> gallery-1.jpg
- gallery-2-placeholder.svg -> gallery-2.jpg
- gallery-3-placeholder.svg -> gallery-3.jpg
- gallery-4-placeholder.svg -> gallery-4.jpg

Then update the corresponding `.svg` filenames in `index.html` to the `.jpg` filenames.

## Reviews
The website displays the current 4.8 rating and review count from the Google business result. The individual review cards are deliberately written as summaries rather than fabricated direct quotes. Add exact customer wording only if you have permission to republish it.

## Contact
The enquiry form opens WhatsApp to +91 74835 92376. Confirm that this is the property's preferred contact number before publishing.
